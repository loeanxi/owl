# 研究工作台提示词管理

在研究工作台点击“提示词管理”，可以维护研究指令预设，选择一份预设并一键覆盖工作台的默认研究指令。

## 使用

1. 选择已有预设，或点击“新增”创建自己的预设。
2. 填写名称和提示词正文；来源链接用于记录参考资料，不会自动下载或执行链接中的内容。
3. 点击“保存”保存预设库。要让所选提示词生效，点击“保存并一键覆盖”。
4. 观察面板中的启用状态和当前预设。已有研究对话和新建研究对话从下一轮开始读取最新配置，正在执行的这一轮继续使用其开始时的提示词。
5. 点击“恢复默认”停用自定义覆盖，保存的预设仍可继续编辑和重新启用。

空白正文可以作为草稿保存，不能启用。保存或覆盖失败时会显示错误；编辑内容保留，修正问题后可以重试。导入的内容先进入编辑状态，保存或启用后才会影响运行。

## 模型分类与筛选

在“模型分类”中选择 GPT、Claude、Gemini、Grok、DeepSeek、Qwen、GLM、Llama 等模型族，可以筛选对应的提示词；关键词搜索可继续按名称、说明、来源或模型标签缩小范围。“全部模型”查看完整预设库，“通用”查看没有特定模型目标的研究方法。没有匹配项时可以重置筛选。

每份预设的“适用模型”允许多选。分类表示作者声明或用户整理的目标模型，不代表已经验证当前版本有效。未知实际模型的客户端模板放在“其他 / 客户端模板”，不根据客户端名称推定它使用哪个模型。

切换分类、搜索和选择预设只改变管理界面的展示，不改变正在启用的覆盖，也不切换研究会话的模型。筛选后保存和导出仍处理完整预设库，其他分类中的条目和未保存编辑会保留。新增预设会沿用当前分类；未填写标签的原有条目按名称和来源文件提供分类，无法识别时显示为通用。

预设库最多保存 500 份提示词，完整 JSON 最多 2,000,000 字节，单份正文最多 48,000 个字符。来源原文、固定版本及校验记录可以另行归档，原始 Skill 模板的辅助变量不会自动展开，导入也不执行安装脚本。

## 覆盖范围

覆盖的是研究会话中可编辑的角色、研究方法和交付指令。工具使用和结果展示所需的固定契约仍会加入最终提示词。普通聊天、模型选择、审批设置和模型实验预算沿用各自设置。

配置保存在当前 Owl 数据目录下的 `research-prompts.json`，按数据目录隔离。它随本机配置保留，不依赖当前项目的浏览器存储；切换工作区时仍使用同一 Owl 数据目录的预设。文件保存使用临时文件写入后替换，校验失败不会覆盖现有配置。

默认研究指令的预览展示可编辑部分，便于复制和修改；它不是包含全部系统上下文、项目指令和工具说明的最终模型请求。

## 导入与导出

可以导入本地 Markdown、纯文本提示词或 JSON 预设库，并导出 JSON 备份。导出由本地服务写入下载目录，界面显示实际保存路径；导出未保存的编辑也不会改变当前启用设置。文本作为提示词正文，不执行其中的命令；JSON 中的启用状态不会直接触发覆盖。

预设库的数据结构如下。名称、正文和来源是示例，导入本身不表示这些内容已经生效。

```json
{
  "version": 1,
  "enabled": false,
  "activePresetId": null,
  "presets": [
    {
      "id": "evidence-review",
      "name": "资料核对",
      "content": "先核对资料来源和时间，再区分观察、推断与待核实内容。用简短中文给出结论和可复核依据。",
      "modelFamilies": ["general"],
      "sourceUrl": "https://example.com/research-notes"
    }
  ]
}
```

## 桌面桥与运行期

`research.prompts.get` 读取预设库和默认可编辑提示词；`research.prompts.save` 保存预设库；`research.prompts.apply` 启用所选预设；`research.prompts.restore` 恢复默认。四种操作返回 `{ settings, defaultPrompt }`。`research.prompts.export` 校验传入的预设库后写入独立导出文件，返回 `{ savedPath }`。

研究扩展在每轮 `before_agent_start` 中读取当前数据目录的配置，无需重建已有会话或重载静态分析后端。新功能的桌面桥和界面源码需要由项目现有的 Owl Dev 入口编译后加载。
