# 研究工作台失败诊断与正常任务验收

研究任务结束后，工作台根据本轮实际消息和工具记录保存原因。正常回答默认不显示提示；出现失败或拒绝候选时显示一条简短状态，展开可查看来源和有界证据。无需选择研究方向或开启新菜单。

## 原因的含义

| 分类 | 判定依据 | 能说明什么 |
|---|---|---|
| 上游拒绝标记 | Responses 明确 refusal 内容，或 Anthropic refusal、Completions content_filter 等原始标记 | 上游提供了拒绝或过滤记录；是否误拒绝仍需核对具体任务 |
| 文本拒绝候选 | 最后一段模型答复开头呈现明确拒绝措辞，未提供上游标记 | 需要核对的候选，不断言服务器审核 |
| 本地审批阻止 | 实际用户否决或计划模式阻止的工具结果 | 工具审批原因 |
| 工具边界阻止 | 已实现研究工具的路径、输入或会话证据边界错误 | 操作超出实际工具范围 |
| 能力或依赖缺失 | 既有工具明确 unsupported、toolMissing、invalidConfiguration 等记录 | 配置或工具能力问题 |
| 请求或工具错误 | 实际错误记录，无明确拒绝标记 | 保留错误证据，不推定内容审核 |
| 取消 | 模型或工具的实际取消状态 | 任务没有验证完成 |
| 未独立验证 | 没有已识别的失败标记 | 响应结束不能证明研究目标完成 |

Responses 的明确拒绝保留 `AssistantMessage.refusal`、原文及原始 `rawStopReason`，规范状态为 `error`。拒绝记录不因自定义重试关键词或上下文超限措辞再次提交。普通技术错误仍按已有恢复策略处理。

诊断在研究会话 JSONL 的 `owl-research-diagnosis` 条目保存，字段版本为 1。恢复读取当前分支最新条目并严格检查会话归属，损坏或异会话记录不能回退到旧诊断。开始下一轮时界面清除上一轮提示。完整原回应仍在会话记录中；诊断只复制最多 24 条、每条 1200 字符的脱敏摘录。

这套功能不能关闭第三方模型服务端的内容审核。它解决状态误报和正常研究流程中的原因不明，也不会把模型自己宣称成功当成独立验收。

## 有界的真实模型验收

仓库脚本 `scripts/run-research-acceptance.mjs` 默认只输出计划，不调用网络模型。`--live` 才执行真实 SDK `AgentSession`、研究扩展、模型工具调用和 REA 后端；这不是仅返回文本的内置模型评测。

```powershell
# 从仓库根目录运行；默认无真实模型请求
node scripts/run-research-acceptance.mjs

# 明确授权真实调用后，使用已有配置模型
node scripts/run-research-acceptance.mjs --live --agent-dir D:\owl\owl-re-v1\data\owl --output .validation\research-acceptance\run-1
```

脚本默认选择 `zai-coding-cn/glm-5.3-flash` 和 `github-copilot/gpt-6-luna`；可用 `--models provider/model,provider/model` 明确指定最多两个已有物理模型。不新增服务商、不修改用户模型默认值。每个模型测试 JS 调用链和只返回常数的自建 PE 两种微型样本；最多每任务 3 次、合计 12 次模型请求，每响应 1536 tokens。失败计入尝试次数，缓存预热、自动重试和压缩关闭。

工具限制只允许读取当前样本目录、写 `analysis.json`、调用相应静态 REA 操作及保存本会话进度；不运行目标、不访问目标网络、不调用其他模型。测试不加载工作区指令、全局技能或其他插件，因此结果代表这条隔离的研究流程，不代表用户的所有自定义组合。

独立检查核对输入哈希未变、实际工具结果、目标身份、产物存在及哈希、预期返回值和调用链。缺失证据、错误结果和只有完成措辞都未通过。每项任务保留输入清单、prompt、完整工具/模型消息、用量、诊断、核验结果、JSONL 会话和 REA 原始证据。

出现传输错误或无法确定请求是否已交付时停止后续真实调用。已确认仅为宿主本地预算耗尽的旧记录可用 `--prior-results path/to/results.json` 续测剩余预定模型；旧请求会导入同一共享预算，不重新领取额度。SDK 的 `usage.cost` 来源于模型目录价格，是估算值，不表示实际订阅扣费或账户账单。

微型样本通过不能证明所有逆向任务都能完成，也不能证明审核失效；未观察到拒绝的样本不能用于宣称误拒绝率已经降为零。
