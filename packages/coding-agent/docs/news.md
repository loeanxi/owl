# Owl 资讯

Owl 的内置资讯模块基于 KKKKhazix/AIHOT 的内容规则移植。界面入口在左侧活动栏，与聊天并列；内容库按 Owl 用户数据目录保存，不随编码项目或聊天切换。

## 开始使用

1. 打开「资讯」直接进入「最新资讯」。首次阅读启用 8 个推荐公开 RSS，自动获取来源标题和摘要；无需 API Key，也不调用模型。已明确停用、修改或删除的信源保持原样。
2. 首次打开后启用免费后台阅读调度，离开资讯页面仍按各信源间隔自动更新，重启后恢复；无需打开高级采集或模型开关。每源每轮最多读取 30 条，不受 AI 精编的条数限制。来源失败保留已有内容，自动从 2 分钟逐步退避到最长 1 小时；手动刷新合并 60 秒内的重复请求。信源页显示免费阅读自身的最近同步、错误与下次更新，不混用高级采集状态。
3. 「模型排行榜」默认提供 LiveBench 2.0 综合能力、Arena 网页开发与 Artificial Analysis 综合智能三个独立榜单，支持搜索模型、查看原始数据和手动同步。SWE-bench 旧子榜收进「历史与参考榜单」。正常缓存 30 分钟，失败保留上次结果；超过 30 天未更新的源显示数据较旧，无来源日期的源显示无法核验时间，同步成功不代表评测数据刚发布。
4. 「问 Owl」按需展开。信源订阅和「AI 与高级设置」放在收起的「阅读设置」中；中文精编、精选评分、深度讨论及自定义信源仍可选用。

高级后台采集与模型调用仍默认关闭，与免费 RSS 阅读相互独立。开启模型处理前可检查请求次数上限；未知价格不视为免费。高级设置保留各处理步骤的独立模型、运行记录、回执和内容管理。X 使用 SocialData、公众号使用 Dajiala；对应服务密钥只显示是否配置。Embedding 未开启时按文字重合度召回事件候选。

免费资讯先展示信源标题和现有摘要，再补齐缺失或仅有图注的摘要：优先使用原站页面描述，其次提取最多 600 字的正文摘录，不调用模型、不保存或分发全文。每轮最多补抓 12 个页面，单篇最多 5 秒、512 KiB；成功缓存 7 天、失败缓存 2 小时。来源返回 304 时仍会逐轮补齐缓存中缺失的摘录。无法读取正文时保留卡片并提示打开原文，不显示虚假的“正在处理”。

页面后台刷新保留当前列表与阅读正文，仅同一查询更新已有内容；暂时失败保留缓存并可自动恢复。任务忙闲和信源同步状态不会让文章列表整块重载。隐藏的资讯页面不轮询、不读取隐藏面板；分类筛选保持稳定，收藏数量减少后自动回到有效页。

排行榜直接发现 [LiveBench 当前官网](https://livebench.ai/) 的部署版本，读取该部署所声明的 CSV、分类和模型目录，并使用网站显示的更新日期；不再读取停留在 v1 的 GitHub 仓库。[Arena 网页开发榜](https://arena.ai/leaderboard/code/webdev) 保留官方排名、投票截止时间和评分区间，直连受阻时通过免密 Jina 只读通道读取同一官方快照；其指标是用户偏好评分，不能视为代码修复正确率。[Artificial Analysis](https://artificialanalysis.ai/leaderboards/models) 从官方公开表读取 Intelligence Index、每任务费用与输出速度，该表不披露统一评测更新时间，界面保持未知。[SWE-bench 旧同环境子榜](https://github.com/SWE-bench/swe-bench.github.io/blob/master/data/leaderboards.json) 仅供历史参考。分数不跨榜合并，未知结果不填零；远端代码只解析文本，不执行。旧数据源缓存与当前官网缓存隔离，避免换源后继续展示旧快照。

## 内容规则

同一网址或 X 帖子幂等入库，内容变化形成新版本。预筛阻止明显无关资料；同一模型独立评分两次，结构抽取与评分并行；够分只成为候选，归组确认阅读增量后才进入精选。官方一手、官方账号和媒体的默认平均分门槛分别为 60、65、76，可用标注样本在「精选评测」重新校准。

事件区分同一事实、同一事件的新进展和无关报道；综合稿只挂靠，不连接两个事件。人工编辑和归属保留，不被后台自动处理覆盖。热点按最近 48 小时独立参与方计算，24 小时半衰期，与 6 小时前比较。

日报按规则成刊，不调用模型；周报和月报从日报汇编，模型仅写总述和栏目导读。默认采用 UTC+8 的刊期：日报 08:00，周一周报 10:00，每月 1 日月报 10:30。过了截止才确认的内容进入下一期，停机后补跑已到期刊物。初次发现的旧文章、初次信源存量和历史回灌不会伪装成刚发生的新闻。

全文展示与全文再分发是两个独立许可；默认都关闭。撤回、隔离和预筛阻止的内容不会出现在公共查询、RSS、MCP 或助手引用中；本地管理页仍可诊断和恢复。旧刊物快照保留，读取时按当前撤回与许可投影。

## 与 Agent 交互

点击资讯或事件上的「问 Owl」，添加一条或两条来源；可讨论选中的段落、比较报道或解读一期刊物。建议问题仅填入草稿；发送后才调用模型。回答附上来源，点击引用回到阅读页。「带入当前聊天」准备问题、选段、回答和来源，由用户决定发送。

聊天 Agent 可使用 `news_search`、`news_read`、`news_hot`、`news_report` 和 `news_open`。这些查询工具在计划模式可用，不采集、不调用模型，也不能修改信源或配置。返回的外部内容是待核对数据，不是指令。

## 对外读取与推送

地址沿用当前 Owl 桥端口，默认只监听本机。公共入口仅提供已发布内容；管理操作使用桌面连接。

| 地址 | 内容 |
|---|---|
| `/api/news/v1/leaderboard` | 模型测评榜单、来源、测评日期与同步状态；公开入口不接受强制刷新 |
| `/api/news/v1/items?mode=selected` | 精选；`mode=all` 为全部；`q`、`category`、`topic`、`limit`、`offset` 可筛选分页 |
| `/api/news/v1/items/{id}` | 资讯详情 |
| `/api/news/v1/stories/{id}` | 事件与报道 |
| `/api/news/v1/hot`、`/api/news/v1/topics` | 热点和主题 |
| `/api/news/v1/reports/{daily,weekly,monthly}/{key,latest}` | 已成刊日报、周报和月报 |
| `/api/news/feed.xml` | 精选 RSS；`?mode=all` 为全部，`?fulltext=true` 仍检查分发许可 |
| `/api/news/feed/{daily,weekly,monthly}.xml` | 刊物 RSS |
| `/api/news/markdown`、`/api/news/agent`、`/api/news/llms.txt` | Markdown 查询、发现说明和机器阅读提示 |
| `/api/news/openapi.json`、`/api/news/mcp` | 接口说明和只读 Streamable HTTP MCP |

外部脚本使用 `POST /api/news/ingest`，传 `Authorization: Bearer <推送密钥>`。密钥在资讯设置的 `ingest` 项写入，至少 16 字符。正文为 `{ "sourceId": "已创建的external信源ID", "items": [{ "title": "标题", "url": "原文地址", "body": "可选正文", "publishedAt": "带时区的ISO日期" }] }`。单次最多 50 条、每客户端每分钟最多 10 次；缺少密钥不能写入。

## 保存、退出与恢复

SQLite 数据库在 `<Owl数据目录>/news/news.sqlite`；服务密钥单独存在 `news/secrets.json`，不返回明文。备份入口创建一致的 SQLite 副本；服务密钥和 Owl 模型凭据不包含在该副本中。恢复副本需先关闭 Owl，保留原库备份后替换数据库，再重新启动并核对密钥配置。

关闭窗口仍在托盘运行；真正退出前会等待当前付费调用收尾，最多约三分半。异常退出后，已收到的模型回答从回执恢复，未知结果不会自动重新购买；管理员核对服务侧结果后再明确释放重试。已收到但格式无效的回答也保留原始输出和用量，只重试对应步骤，不重复购买已成功的两次评分。
